نسخة Mobile-first فاخرة بنمط Classic Executive / Corporate Real Estate.

## V10 highlights
- iPhone-style vertical navigation rail on the right side.
- Classic navy / ivory / champagne-gold visual system.
- Executive dashboard designed as an office management system.
- Smart Client Requests: type natural Arabic requests such as `شقة 3 مليون` or `عمارة 10 مليون` to find matching clients.
- Client request matching supports Arabic numerals and common Egyptian number words.
- Property selection and multi-page PDF export remain available.
- Backup / restore and existing property/client workflows preserved.
