# DREAM HOUSE — Mobile Executive V9

A mobile-first real-estate management workspace for iPhone-sized screens.

## V9 improvements
- Right-side vertical iOS-inspired floating navigation rail; no bottom navigation on mobile.
- Consistent executive/enterprise visual system with restrained glass for navigation and solid readable content surfaces.
- Improved mobile login experience with a dimensional executive-style presentation.
- Property selection is persistent across search/filter changes.
- Added "تحديد الكل" in addition to "تحديد الظاهر".
- PDF export uses every selected property in one report and automatically creates as many pages as needed (4 property cards per page).
- Selection counter now shows selected count against total database count.
- Removed stale selected property IDs when records are deleted.
- Full project files are included in the ZIP.

## Main files
- `index.html` — UI and page structure
- `final.css` — full responsive design system
- `app.js` — application logic, local storage, selection, backup/restore, and PDF export
- `platinum.css` — supplemental premium styling
- `netlify.toml` — deployment configuration
